# Northwind Hotel - Client

This is the client for use with the [Northwind Hotel API](https://github.com/CosmicCapycino/NorthwindHotel-API).

Built using Vue 3, and makes use of Vuetify, Router, and Axios.

To run this app:

1. Clone the repo
2. Open a terminal and run
   ```npm install```
3. Run ```npm run serve```
4. Open a browser and go to the link displayed in the terminal

#### NOTE: This is a portfolio project and is intended to demonstrate my development skills. None of the accessible information is real. All information displayed has been generated using [Mockaroo](https://www.mockaroo.com/).
